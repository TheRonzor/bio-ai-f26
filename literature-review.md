# Literature review on [topic]
## Objective
Discover published, peer-reviewed papers on the topic. Provide links
to the papers, an executive summary, and a breadcrumb trail of the
search procedure.

## Criteria
- N = 10
- Include papers that directly study [population/system/text/case],
[phenomenon], and/or [method/theory]. Exclude papers that only
mention the topic in passing.
- If more than N papers are discovered, only include the N most
relevant. If less than N papers seem directly relevant then include
less, do not artificially inflate the results.
- Search across [if your field has a specific set of databases or
journals, list them here. Otherwise, exclude, but beware that this
will result in more variability in the results]
- [Optional: Provide a date range]
- [Optional: Specify whether you are looking for
empirical/theory/review papers if relevant]

## Executive summary
An approximately 1,000 word summary:
- Directly reference the papers included to back up statements of
fact
- Clearly identify claims, evidence, and inferences
- Highlight areas where the papers agree or disagree
- Summarize apparent open questions on the topic, or related to the
topic

## Search procedure
Create a search-log.txt file that contains one entry per paper with:
1. Search terms used
2. Databases/search engines checked
3. Date searched
4. Inclusion/exclusion criteria
5. Included papers, with reasons for inclusion
6. Any uncertainty or access limitations
7. Near misses, with reasons for exclusion

## Citations
- Do not invent sources. Verify each item against a publisher page,
DOI page, database record, or institutional source.
- Provide a literature-review.csv file that contains columns:
- Title
- Authors
- Publication Date
- Journal
- Reviewed Material
- One of: Full text, Abstract only, Title and metadata only,
Other
- Source
- DOI where available. If no DOI is available, fallback to a
URL
- Summary: 100 words or less explaining why this paper is
relevant to the topic
